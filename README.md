# WorkPulse – Система управления бизнесом (MVP)

WorkPulse — упрощённая система управления командой внутри компании. Приложение позволяет регистрировать пользователей, объединять их в команды, ставить задачи, оценивать работу и планировать встречи.

---

## Возможности

### Пользователи

- Регистрация по email и паролю  
- Авторизация и выход из системы  
- Роли: пользователь, менеджер, администратор  
- Просмотр и обновление профиля  
- Удаление аккаунта без восстановления  
- Привязка к команде (через email и роль)

### Команды

- Создание команд администратором  
- Добавление пользователей в команду по email  
- Просмотр состава команды  
- Назначение ролей в рамках команды (USER / MANAGER)

### Задачи

- Создание задач руководителем (MANAGER)  
- Назначение исполнителя по email  
- Поля: заголовок, описание, дедлайн, статус  
- Изменение / удаление задач (через API / админку)  
- Комментарии к задачам (упрощённый чат)  
- Статусы: открыто, в работе, выполнено

### Оценка работы

- Оценка выполненных задач менеджером: от 1 до 5  
- Просмотр своих оценок пользователем  
- Сводка оценок (агрегация по задачам / пользователям в API)

### Встречи

- Создание встреч: дата, время, описание  
- Привязка к участникам по пользователям команды  
- Проверка времени на пересечения (реализуется в бизнес-логике)  
- Список встреч пользователя  
- Отмена встречи

### Календарь

- Текстовое отображение встреч по дням  
- Дневной и месячный режим (параметр `period=day|month`)  
- Автоматическое включение встреч в календарь

### Админ-панель

- Готовая админка на основе `sqladmin`  
- Управление пользователями, командами, задачами и связанными сущностями через UI

## Стек технологий

- **FastAPI** — основной веб-фреймворк  
- **SQLAlchemy** + **Alembic** — ORM и миграции  
- **PostgreSQL** — основная БД (прод)  
- **SQLite** — БД для тестов / локальной разработки  
- **Pydantic** — схемы и валидация  
- **fastapi-users** — регистрация, логин, JWT, управление пользователями  
- **sqladmin** — готовая админ-панель  
- **Jinja2** — рендер простых HTML-страниц  
- **Uvicorn** — ASGI-сервер  
- **Docker** (опционально) — контейнеризация приложения

## Архитектура

Проект реализован как монолитное FastAPI-приложение без микросервисов.

Основные директории:

```text
app/
  main.py              # точка входа, создание FastAPI-приложения
  database.py          # подключение к БД и session
  models/              # SQLAlchemy-модели (User, Team, Task, Meeting, Evaluation, Comment)
  schemas/             # Pydantic-схемы
  routers/             # роутеры по доменам: user, team, task, meeting, comment, evaluation, calendar
  auth/                # конфигурация fastapi-users, JWT
  templates/           # Jinja2-шаблоны (index, users, teams, tasks, ...)
  static/              # styles.css, app.js
  admin/               # настройка sqladmin
alembic/               # миграции
alembic.ini
```

Главная страница (`/`) — упрощённый фронтенд (Jinja2 + чистый JS), который позволяет:

- Зарегистрировать пользователя  
- Залогиниться (получить JWT)  
- Перейти на страницы управления пользователями, командами, задачами, оценками, комментариями, встречами и календарём  
- Выйти из системы (клиентский logout: очистка `localStorage` и токена в памяти)

## Установка и запуск

### Требования

- Python 3.10+  
- PostgreSQL (для рабочего режима)  
- SQLite (по умолчанию может использоваться для локального запуска)  
- Опционально: Docker и Docker Compose

### Клонирование репозитория

```bash
git clone <url-репозитория>
cd <папка-проекта>
```


### Установка зависимостей

```bash
poetry install
```

### Настройка окружения

Создайте `.env` и укажите:

```
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/workpulse
SECRET_KEY=your_secret_key_here
```

Для тестов можно указать SQLite:

```
DATABASE_URL=sqlite+aiosqlite:///./test.db
```

### Миграции

```bash
alembic upgrade head
```

## Запуск приложения

#### Локальный запуск через `uvicorn`:

```bash
uvicorn app.main:fastapi_app --reload --port 8001
```

После старта:

- API и документация:  
  - Swagger UI: `http://localhost:8001/docs`  
  - ReDoc: `http://localhost:8001/redoc`  
- Мини-панель (Jinja2):  
  - `http://localhost:8001/`

### Запуск через Docker (FastAPI + PostgreSQL)

Для удобного запуска можно использовать Docker Compose: один контейнер с приложением и один с PostgreSQL.

Запуск
```bash
docker compose up --build
````
После старта:

Мини‑панель (Jinja2): http://localhost:3001/

Swagger UI: http://localhost:3001/docs

ReDoc: http://localhost:3001/redoc

## Мини‑фронтенд

Фронтенд — это набор Jinja2-шаблонов и одного JS-файла:

- `app/templates/index.html` — логин, регистрация, навигация  
- `app/templates/users.html` — просмотр пользователей  
- `app/templates/teams.html` — создание команды, добавление пользователей, просмотр состава  
- `app/templates/tasks.html` — создание и просмотр задач  
- `app/templates/evaluations.html` — выставление и просмотр оценок  
- `app/templates/comments.html` — комментарии к задачам  
- `app/templates/meetings.html` — создание и просмотр встреч  
- `app/templates/calendar.html` — календарь встреч

В `app/static/app.js` реализованы:

- логин/регистрация (`/auth/register`, `/auth/jwt/login`)  
- хранение `accessToken` в `localStorage`  
- обёртка `authedFetch` для вызовов защищённых эндпоинтов  
- функции работы с сущностями: пользователи, команды, задачи, оценки, комментарии, встречи, календарь  
- `logoutUser()` — клиентский логаут

Статические файлы раздаются через:

```
app.mount("/static", StaticFiles(directory="app/static"), name="static")
```

и подключаются так:

```html
<link rel="stylesheet" href="{{ url_for('static', path='styles.css') }}">
<script src="{{ url_for('static', path='app.js') }}"></script>
```

## Админ‑панель

`sqladmin` инициализируется в `app.admin.init_admin(app)` и предоставляет веб‑интерфейс для:

- просмотра и редактирования пользователей  
- управления командами, задачами, встречами и оценками  

URL админки задаётся в `admin`‑модуле (например, `/admin`).
